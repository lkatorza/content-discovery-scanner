# content-discovery-scanner
A lightweight Python script designed for directory and file brute-forcing during security testing and web reconnaissance.

## Features
- Custom wordlist integration
- Filtering based on HTTP status codes (skips 404 Not Found)
- Automatic saving of discovered paths to `result.txt`
- Built-in timeout handling for speed and reliability

## Usage
1. Clone the repository:
   git clone https://github.com/lkatorza/content-discovery-scanner.git

2. Run the script with Python 3:
   python3 scanner.py
